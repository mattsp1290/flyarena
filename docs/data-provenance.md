# MaleCNS graph provenance

This document is the human-readable explanation of how
`public/data/malecns-arena-v1.bin.gz` (and its rewired control,
`malecns-arena-v1-rewired-seed0.bin.gz`) were produced. The machine-readable
version of the same facts is `public/data/malecns-arena-v1.ledger.json`,
written by the same compiler run that produced the binary; if this document
and the ledger ever disagree about a number, the ledger (regenerated by
`uv run python scripts/data/compile.py`) is authoritative.

Per `docs/model-ledger.md`'s vocabulary: the graph **topology** below is
**measured** (real MaleCNS synapse reconstructions); neuron **classes** and
**neurotransmitter predictions** are **annotated** (source-dataset
metadata, not a measurement of simulated behavior); the **node/edge
selection rules**, the **8-channel/3-population wiring**, and the
**Dale's-law sign policy for ambiguous transmitters** are **authored**
engineering decisions; `globalGain` is **calibrated** from the compiled
edge set by a documented formula (not a free-hand constant).

## Source dataset

- **Name / version:** Male CNS Connectome, release `v1.0` (neuPrint dataset
  `male-cns:v1.0`).
- **Publisher:** Janelia FlyEM Project (HHMI), in collaboration with the MRC
  Laboratory of Molecular Biology (Cambridge) and Google Research.
- **Project page:** <https://male-cns.janelia.org/>
- **License:** CC BY 4.0 (<https://creativecommons.org/licenses/by/4.0/>),
  per the attribution statement on the dataset's download page: "The Male
  CNS dataset is licensed under CC-BY."
- **Access:** the flat-connectome export tables used here are served
  unauthenticated over HTTPS from the public Google Cloud Storage bucket
  `gs://flyem-male-cns` (also reachable at
  `https://storage.googleapis.com/flyem-male-cns/...`). No neuPrint account
  or auth token was needed for these three files; this was verified with
  plain `curl` HEAD/GET requests before writing `scripts/data/download.py`
  (see "How public access was confirmed" below).

### What was not downloaded

The same bucket directory also hosts several much larger flat-connectome
tables this compiler does not need and intentionally did not download:
`body-stats-*.feather` (780 MB, synapse-count summary statistics --
derivable from the weights table for the neurons we keep),
`syn-points-*.feather` (13 GB, individual synapse point coordinates),
`syn-partners-*.feather` (6.8 GB, per-synapse partner pairs at the
individual-synapse rather than aggregated-connection level), and
`tbar-neurotransmitters-*.feather` (2.7 GB, per-presynapse rather than
per-neuron transmitter predictions). None of these are required to select a
node/edge subgraph and build the CSR graph; `body-neurotransmitters-*`
already gives one transmitter call per neuron, which is what the
presynaptic sign policy needs.

## Node selection policy

All constants below live in `scripts/data/compile.py` (search for the name
in `ALL_CAPS`) and are also emitted verbatim into
`malecns-arena-v1.ledger.json`'s `selectionPolicy` block, so the ledger
alone is enough to reproduce this section's numbers.

1. **Eligibility filter.** Only neurons with `status == "Traced"` in the
   body-annotations table are eligible for anything below. This excludes
   `Orphan` (disconnected reconstruction fragments), `Glia`,
   `Unimportant`, `Assign` (still under review), and `Anchor` (placeholder)
   bodies. Of 211,577 total annotated bodies, 165,122 are `Traced`.
2. **Sensory input candidates (`S0`).** Real VNC (ventral nerve cord)
   sensory neurons (`superclass == "vnc_sensory"`), restricted to the two
   `class` values most analogous to this POC's abstracted egocentric
   channels -- wall clearance, speed, food/hazard bearing and distance
   (`src/lib/arena/sensors.ts`'s `OBSERVATION_CHANNELS`) -- namely
   `mechanosensory_tactile` and `mechanosensory_proprioceptive`. This
   deliberately excludes the optic-lobe visual pathway (`ol_sensory`) and
   central-brain chemosensory pathways (`cb_sensory`): this arena's 8
   declared channels are not an attempt to model real photoreceptor or
   olfactory-receptor input, and a proprioceptive/tactile sensory
   population is the closer real analog for an abstracted locomotor-control
   task. 3,588 traced neurons match.
3. **Descending-neuron output candidates (`D0`).** Neurons with
   `superclass == "descending_neuron"`: the real anatomical class whose
   axons leave the brain through the neck connective to drive VNC motor
   circuits -- the direct biological analog of this POC's thrust/yaw/brake
   output populations (`src/lib/arena/actions.ts`'s `OUTPUT_POPULATION`).
   1,314 traced neurons match.
4. **Downselection by measured degree.** `S0`/`D0` are ranked by total
   measured synapse-count degree (sum of connection `weight` over every
   edge touching that body, computed on the traced-only subgraph), and the
   top `SENSORY_TARGET = 160` / `DESCENDING_TARGET = 48` are kept (`S`,
   `D`). These numbers were chosen as round multiples of the channel/
   population counts (160 / 8 channels = 20 each; 48 / 3 populations = 16
   each) and to prioritize well-reconstructed, well-connected neurons over
   sparse fragments.
5. **Bridge population.** Sensory and descending neurons essentially never
   synapse on each other directly in a real connectome; a multi-synaptic
   path is needed. The bridge set is every neuron that is simultaneously
   (a) a direct postsynaptic partner of some neuron in `S` and (b) a direct
   presynaptic partner of some neuron in `D` -- i.e. the middle node of at
   least one real `S -> bridge -> D` two-edge path. This 1-hop-each-
   direction search already produced 2,557 candidates (a deeper BFS was not
   needed to reach a densely-connected, budget-sized subgraph); they are
   ranked by the same degree measure and capped at `BRIDGE_TARGET = 800`.
6. **Final node set.** `S ∪ D ∪ bridge`, deduplicated and sorted by
   ascending body ID: **1,008 neurons** (160 sensory + 48 descending + 800
   bridge).
7. **Edge selection.** Every row of the full connection-weight table where
   both `body_pre` and `body_post` are in the final node set, filtered to
   `weight >= SYNAPSE_THRESHOLD = 3` (a connection-level noise filter on
   top of the source data's own synapse-confidence filtering at
   `minconf-0.5`): **46,311 edges**. All three neuron populations were
   verified to remain non-isolated at this threshold: every one of the 160
   selected sensory neurons has at least one outgoing edge in the final
   graph, every one of the 48 selected descending neurons has at least one
   incoming edge, and `isolatedNodeCount` (nodes with zero edges at all) is
   `0` -- see `malecns-arena-v1.ledger.json`'s `compileStats`.

## Input/output channel mapping (authored)

`src/lib/arena/sensors.ts` declares 8 input channels
(`foodBearing, foodDistance, hazardBearing, hazardDistance,
forwardClearance, leftClearance, rightClearance, speed`);
`src/lib/arena/actions.ts`'s `OUTPUT_POPULATION` declares 3 output
populations (`thrust = 0, yaw = 1, brake = 2`).

This mapping from the 160 sensory / 48 descending neurons to those channels
is **authored, not biologically derived**: it does not claim that any
specific real neuron "is" the food-bearing sensor. The rule
(`assign_channels` in `scripts/data/compile.py`) is a simple, fully
deterministic partition: sort the selected neurons by ascending body ID and
split into equal contiguous blocks, one block per channel/population (20
sensory neurons per input channel; 16 descending neurons per output
population). `inputWeight` is a flat `1.0` (channel values are already
normalized by `sensors.ts` before this weight is applied); `outputWeight`
is `1 / (population size)` so a population's aggregated output magnitude
does not scale with how many neurons happen to land in it.

## Presynaptic sign policy (Dale's law)

The wire format applies one `+1`/`-1` sign per presynaptic neuron to every
edge it emits (`presynapticSigns`, see `docs/graph-format.md`). The sign is
derived from `body-neurotransmitters-male-cns-v1.0.feather`'s
`consensus_nt` column (an **annotation**: the source dataset's aggregate
per-neuron transmitter prediction), via an **authored** mapping:

- `acetylcholine` -> **excitatory (`+1`)**: the dominant fast excitatory
  transmitter in the fly CNS.
- `gaba`, `glutamate` -> **inhibitory (`-1`)**: GABA is the dominant fast
  inhibitory transmitter; glutamate is treated as inhibitory here (the
  dominant glutamate receptor class in the fly CNS is the ionotropic
  glutamate-gated chloride channel), matching the convention used in prior
  connectome-constrained rate-model work.
- Anything else -- `dopamine`, `octopamine`, `serotonin`, `"unclear"`, or a
  body with no neurotransmitter-table row at all -- is **defaulted to
  excitatory (`+1`)** and counted separately, since these are
  neuromodulatory or low-confidence calls this POC does not attempt to
  model directionally.

In the compiled artifact, 51 of 1,008 neurons (5.1%) fell into the
"unknown, defaulted" bucket: 50 `"unclear"` and 1 `"serotonin"`. See
`malecns-arena-v1.ledger.json`'s `unknownTransmitters` block for the exact
counts. Every one of the 1,008 selected neurons had *some* row in the
neurotransmitter table (`missing` count: 0).

## Dynamics parameters

`timestepSeconds = 1/30`, `leakRate = 0.35`, `rateMin/rateMax = -2/2`, and
`inputClampMin/inputClampMax = -1/1` are fixed, authored constants shared
with the rest of this codebase's test fixtures
(`tests/fixtures/tiny-graph.ts`'s `createRandomGraph` defaults) for
consistency rather than independently derived.

`globalGain` is **calibrated** from the compiled edge set itself
(`calibrate_global_gain` in `scripts/data/compile.py`): compute, for every
presynaptic neuron, the sum of its outgoing `contactMagnitudes`
("`out_sum`"); take the 95th percentile of `out_sum` across all neurons;
solve for the `globalGain` that would make a fully-active neuron at that
percentile contribute exactly `0.5` rate-units of total outgoing recurrent
drive in one substep (`globalGain = 0.5 / out_sum_p95`). This keeps the
bulk of the network's recurrent drive within a bounded, non-saturating
range without a hand-picked magic constant. For the current artifact this
resolves to `globalGain ≈ 1.984e-4` (see the ledger's `dynamics` block for
the exact value).

## Rewired control arm

`public/data/malecns-arena-v1-rewired-seed0.bin.gz` is produced offline by
`scripts/data/rewire.py --seed 0` from the compiled biological artifact
(chosen over generating it in the browser so both arms are equally
reproducible/hashable build artifacts, matching the plan's stated
preference for an offline-compiled rewired control). It implements a
seeded directed double-edge-swap (configuration-model) rewiring: repeatedly
picks two edges `(a -> b)`, `(c -> d)` and, if legal, replaces them with
`(a -> d)`, `(c -> b)`. See `scripts/data/rewire.py`'s module docstring for
the full argument for why this construction preserves in-degree,
out-degree, the edge-weight multiset, sign ownership (per presynaptic
neuron), the node set, and the edge count by construction, not by a
post-hoc repair pass.

**Self-loop / duplicate policy** (a compiler-level decision;
`docs/graph-format.md` takes no position on it): duplicate `(pre, post)`
pairs are always rejected (the wire format cannot represent them), and
**self-loops are disallowed in the rewired arm** (a candidate swap that
would create one is rejected and re-drawn). The biological arm's self-loop
count is a measured quantity to preserve; a rewired null-model control has
no such measurement, and rejecting self-loop-creating swaps is the standard
convention for configuration-model rewiring. In practice the current
biological artifact already has zero self-loops (see the table above), so
this policy is exercised by `tests_python/test_compile.py`'s synthetic
fixtures (which include a deliberate self-loop) rather than by the real
artifact's rewiring run.

For seed 0: 926,220 attempted swaps (20x the edge count) over 46,311 edges,
764,340 accepted (the rest rejected for would-be duplicates, would-be
self-loops, or being a degenerate same-source/same-target pick). See
`malecns-arena-v1.manifest.json`'s `rewiredArms.seed0.swapStats` for the
exact counts.

## Reproducing this artifact

```console
$ uv sync
$ uv run python scripts/data/download.py       # idempotent, hash-verified
$ uv run python scripts/data/compile.py         # writes public/data/malecns-arena-v1.{bin.gz,manifest.json,ledger.json}
$ uv run python scripts/data/rewire.py --seed 0 # writes the rewired control arm and updates the manifest
$ uv run pytest tests_python                    # compiler invariants, no raw data required
```

`compile.py` is deterministic: re-running it against the same pinned source
files reproduces byte-identical `.bin`/`.bin.gz` output (verified directly
-- see `tests_python/test_compile.py`'s determinism tests, and this was
also checked by running the real pipeline twice during development).
`malecns-arena-v1.ledger.json`'s `compilerRevision` field records the git
SHA of this repository at compile time.
